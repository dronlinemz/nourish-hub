# Nourish Hub

visite o website https://dronlinemz.com e veja a paleta de cores e o proposito do site. A partir dessa informacao crie um e-commerce virado a venda de produtos alimentares saudaveis, suplementos de saude, kits de primeiros socorros, equipamentos para estudantes... adicione outras categorias que se adequem ao proposito do e-commerce, desde que nao inclua a venda de medicamentos, e para cada item publicado deve ser visivel ao cliente final quem e o proprietario, o que implica criar uma seccao de criacao de perfis de fornecedores para que o admin associe os produtos e precos ao fornecedor. o site deve incluir tambem gateway de pagamentos por mpesa e uma seccao de submissao de comprovativos de pagamento em caso de transferencias bancarias. o admin deve ter controle total do sistema nas suas mais diversas componentes. monte esse modulo de forma robusta. o cliente que compra os produtos na plataforma nao precisa estar cadastrado, mas se estiver cadastrado, o sistema deve contar com abertura para integracao ao aplicativo principal, que ja conta com uma infraestrutura pronta para colectar esses dados na conta do usuario
